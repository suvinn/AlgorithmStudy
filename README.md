
## SSAFY 서울 2반 알고리즘 스터디

이 레포지토리는 **SSAFY 서울 2반 알고리즘 스터디**를 위한 저장소입니다.
백준(BOJ)의 알고리즘 문제를 **Python**으로 풀이하고, 풀이 코드를 공유합니다.

---

## ⏱ 문제 풀이 권장 시간 기준

문제 난이도에 따라 **아래 시간 내에 풀이를 시도하는 것을 권장**합니다.

* **브론즈**: 20 ~ 30분
* **실버**: 30 ~ 60분
* **골드**: 60 ~ 120분

> 제한 시간 내에 **혼자 고민 → 구현 → 제출**까지 경험하는 것을 목표로 합니다.
> 시간 초과 시에는 풀이를 참고하여 정리해도 괜찮습니다.

---

## 📁 파일 업로드 규칙

문제 풀이 파일은 **아래 형식을 반드시 지켜서 업로드**해 주세요.

```
백준문제번호_이름이니셜.py
```

### 예시

```
1000_ssb.py
```

* 문제 번호는 **백준 문제 번호**
* 이름은 **영문 이니셜**
* 언어는 **Python (.py)**
